# 0.3.0 작업실 아트 제작 기록

2026-11-24 KST. 기준은 `spec.md`, `designs.md`, `tasks/expansion_030.md`와 `game/data/item_catalog.json`이다. 기존 모델과 그림을 보존하고 `game/assets/ui/` 아래 새 이미지 및 아이템 원본을 추가한다.

## 제작 기준

- 아이템 88개: Blender 5.2의 독립 백그라운드 프로세스에서 도안의 종류·지역·형상·재료 특징을 읽어 제작한다. 청록 도장 금속, 황동, 가죽, 목재와 마모된 밝은 모서리를 사용한다. 아이콘은 384×384 RGBA PNG, 같은 메시의 GLB는 프리뷰와 게임 장착 표현에 전달한다. 손잡이 원점에서 +Z가 날/봉 방향, X가 날 너비, -Y가 앞면이다. 착용 장비는 중심 원점이다. 개별 모델은 약 0.5–8천 삼각형을 목표로 한다.
- 기술 6종과 인물 4종: 기존 주인공의 남색 머리·고글·청록 스카프·주황 작업복·짧은 앞치마·간판검을 기준으로 애니메이션풍 일러스트를 제작한다. 기술은 정사각형, 인물은 얼굴과 상체가 작은 화면에서도 읽히는 구도다.
- 지역 6종: 숲·사막·묘지·늪·설산·화산의 길과 랜드마크를 구분하는 컬러 풍경화다. UI가 그림 위에 글자를 굽지 않고 별도로 표시한다.
- 작업실 패널: 따뜻한 어두운 나무와 청록 도장 테두리·황동 모서리, 본문에는 낮은 대비의 빈 여백을 둔다.

## 순서와 검증

1. 도안 담당의 고정 ID·형상 자료와 UI 경로를 확인한다.
2. 기존 주인공과 소품의 색·실루엣을 참조해 아이템 모델, 렌더 카메라와 조명을 만든다. 공유 Blender MCP 장면은 변경하지 않는다.
3. Blender 아이콘을 렌더하고, 내장 imagegen을 자산당 한 호출로 사용해 일러스트를 제작한다. 외부 유료 공급자나 API 키를 사용하지 않는다.
4. 결과를 프로젝트에 저장하고 이미지 크기·알파·모든 ID 파일의 존재와 메시 대응을 검사한다. 대표 아이콘을 64px/128px로 모아 실루엣과 대비를 직접 확인한다. 그림은 실제 표시 비율에서 확인한다.
5. 실제 UI의 가독성·레이아웃·프리뷰 동작 검증은 UI/통합 담당이 수행한다. 아트 생성 또는 파일 존재만으로 이 검증을 통과했다고 판정하지 않는다.

## 완료 결과

2026-11-24 KST 제작 완료. `build_items.py`와 Blender 5.2.1 LTS로 88개 도안의 실루엣과 구성 부품을 각각 만들었다. ID 0의 빨간 화살표 간판검을 기존 주인공·새 초상과 맞췄다. 지역 도안은 단순 색상 교체에 그치지 않고 갈고리·톱니·벨·물레·기어·화로·얼음·뿔·꽃잎·태엽 등의 실제 입체 부품을 다르게 구성한다. 금속·가죽·나무·도장·천·발광 인셋을 분리하고, 미세한 명암 변화도 내보낸 정점 색에 담았다.

- `game/assets/ui/items/item_000.png`–`item_087.png`: 88개 모두 384×384 RGBA. 정투영 스튜디오 조명으로 실제 GLB와 같은 메시를 렌더했다.
- `game/assets/models/items/item_000.glb`–`item_087.glb`: 장착·프리뷰용 정적 메시 88개, 총 17,327,044바이트. 개별 404–8,764삼각형, 전체 도안 합계 240,084삼각형이다. 모든 장비를 동시에 표시하는 예산을 뜻하지 않는다. 8천 목표를 약간 넘는 최대 모델은 ID 33의 도르래 활이다.
- `items_library.blend`: 88개 원본 메시와 재질을 포함한 Blender 원본. 개별 `Item_번호_형상` 오브젝트는 GLB와 같은 로컬 원점과 축을 쓴다. 여러 도안이 같은 위치에 놓여 있으므로 편집 시 선택한 오브젝트만 격리한다.
- 기술 6, 초상 4, 지역 6, 작업실 패널·투명 프레임 2: 내장 imagegen을 자산마다 별도 호출해 제작하고 프로젝트에 복사했다. 모든 정사각형 그림은 1254×1254, 지역 풍경은 1536×1024다. 정확한 프롬프트는 `imagegen_prompts.json`에 보존했다. 외부 유료 3D 공급자·API 키는 사용하지 않았다.

## 실제 검증

`review_assets.py` 통과: 아이콘 88개와 GLB 88개의 ID·형상 이름·삼각형 대응, PNG 크기·실제 알파, 캔버스 경계에 잘린 물체 없음, 각 PNG/GLB의 SHA256 고유성을 확인했다. 그림 18개의 크기와 투명 프레임 중앙 알파 0도 확인했다. 초기 ID 11의 아래쪽 잘림을 발견해 카메라 기울기·회전이 적용된 투영 경계로 프레이밍을 계산하도록 고친 후 88개를 다시 렌더했다.

`items_64.png`와 `items_128.png`에서 전체 도안의 작은 크기 실루엣을 직접 보았고, `illustrations_review.png`에서 전체 그림의 구도·색·캐릭터 특징을 확인했다. 결과 수치와 SHA256은 `asset_validation.json`, 모델 명세는 `item_manifest.json`에 있다.

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' -b --factory-startup --python-exit-code 1 --python art/ui_030/build_items.py
python -X utf8 art/ui_030/review_assets.py
```

아이콘만 재렌더하려면 Blender 명령 마지막에 `-- --render-only`를 붙인다. 선택 도안은 `-- --ids 0,1,29`처럼 지정한다. 기존 스크립트 원본을 수작업으로 변경했다면 재생성 전에 변경을 보존한다.

## 범위와 한계

그림은 실제 시전 영상이 아닌 기술 콘셉트 일러스트이며, 풍경은 실제 필드의 1:1 지도나 지형 캡처가 아니다. 메시와 아이콘의 대응은 검사했지만 실제 캐릭터 본 부착·의복 관통·무기 접점·시전 프리뷰와 UI 720p/150% 가독성은 전투/UI 통합 담당의 별도 게임 검증을 따른다. 정적 장비 자체에는 스킨·애니메이션·충돌을 넣지 않고 기존 캐릭터의 부착점과 행동을 사용한다. 원본 `.blend`는 검수와 재생성용이며 게임은 GLB와 PNG만 읽는다.
