# 캠페인 입력 검증

2026-11-18 13:30 KST. [캠페인 입력 테스트](../tests/campaign_input.gd)는 실제 메인 씬을 열고 WASD, 마우스 조준·클릭, 기술·회피 키, 가방과 마차 버튼으로 진행한다. [첫 원정 검증](first_expedition_results.md)과 같은 입력 경로를 사용한다. 검증 시작 시 새 임시 슬롯을 생성한다. 이어서 시험할 때는 해당 플레이로 축적한 무기·코인·처치·해금 기록을 읽는다.

## 쉬움 여섯 노선과 일반 숲 도착

마차에서 일반 난이도를 선택해 게임 시간 1,308.63초에 일반 숲에 도착했다. 벽시계 385.66초, 사망 60회였고, 등장한 45종의 몬스터를 개체별로 관찰했다. 이 회차의 설산에서는 자동 입력이 반복해서 사망했다. 회차 종료 시 실제 습득·합성과 장착을 거친 무기의 공격력은 41이었다.

## 동일 슬롯에서 일반 난이도 이어하기

쉬움·일반 인식 거리 조정본에서 해당 저장을 재개했다. 후속 입력은 코인이 충분하면 상설 상인의 구매·판매 버튼을 이용하며, 높은 공격력의 무기를 가방 화면에서 장착한다. 피격·사망·보스 체력과 장비 수치에는 게임의 원래 규칙을 적용했다.

일반 숲·사막·묘지 필드보스를 이 구간 시작 후 각각 87.15초, 331.07초, 631.48초에 처치했다. 일반 늪에서는 중간보스 두 번을 처치하고 필드보스의 남은 체력을 최소 72까지 관찰했지만, 사망 후 보스 체력이 복원됐다. 이 구간 전체에서 상점 구매 175회와 공격력 44 장착을 확인했으며, 늪 노선 12분 상한에서 누적 9개 클리어로 일단 종료했다. 이 결과는 해당 자동 전투 전략의 한계를 포함한다.

같은 저장으로 한 차례 더 진행했다. 두 번째 입력 전략은 겹치는 바닥 예고를 함께 보고 회피 방향을 고르고, 강타와 회오리를 실제 사거리 끝에서 사용했다. 늪에 44회 들어가는 동안 일반 몬스터 231마리를 처치하고 33자루를 추가 구매했다. 장착 공격력은 45에 도달했다. 보스 체력 846 중 최소 23을 관찰했지만 사망 43회 후 두 번째 12분 상한에 도달했다. 이 시도를 끝으로 캠페인 입력 검증을 마쳤다.

**판정.** 실제 입력으로 24개 중 9개 노선의 필드보스를 처치했다. 일반 늪까지 10개 노선에 입장했다. 일반 늪의 필드보스부터 불지옥 화산 엔딩까지의 실제 입력 완주는 미확인이다. 세션 테스트에서는 24개 노선의 처치·해금·엔딩 계약을 검증했다. 사람의 조작으로 일반 늪을 통과하는 난이도와 후반 노선의 전투 밸런스는 별도 확인이 필요하다.

[검증 자료](evidence/campaign-20261118.zip)에 세 구간의 전체 로그와 마지막 두 저장 세대를 보존했다. 압축 파일의 각 구성 파일을 원본 바이트와 대조했다. SHA-256은 `b17a615fda6112f0ccfec96c375ef7b98f36f0e09e3f90bc2b02a345d4f59b9e`다.

## 재현

```powershell
godot --headless --fixed-fps 60 --path game --script (Resolve-Path tests/campaign_input.gd).Path -- --target=6
```

테스트는 `CAMPAIGN_SAVE`로 임시 폴더를, `CAMPAIGN_RESULT`로 결과를 출력한다. 같은 슬롯에서 이어갈 경우 `--resume=<출력된 폴더>`를 전달한다. `--target=24`는 마지막 보스 처치와 엔딩 기록까지 검사한다. 개별 구간에서 12분의 게임 시간이 지나도록 새로운 노선이 열리지 않으면 증거를 남기고 종료한다.

보존한 구간을 재개하려면 압축 파일을 새 임시 폴더에 풀고 `-- --target=24 --tactical --resume=<임시 폴더>`를 전달한다. 저장 슬롯은 해당 임시 폴더의 `save`와 연결된다.
