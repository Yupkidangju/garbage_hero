귀환 표석 F 입력과 실제 마을 도착을 별도로 기록하도록 검증을 보강했다. 저장 슬롯 동시 실행 방지, 장비 목록 스크롤과 지형 변경을 적용한 뒤 새 슬롯으로 다시 실행했다. 첫 합성 11.98초, 중간보스 처치 42.67초와 66.75초, 숲 보스 처치 91.90초, 표석 귀환 101.50초, 사막 도착 102.05초였다. 사망 3회, 숲 방문 4회, 벽시계 33.92초였다.

## 재현과 판정 범위

프로젝트 루트에서 리소스를 임포트한 뒤 실행한다.

```powershell
godot --headless --path game --import
godot --headless --fixed-fps 60 --path game --script (Resolve-Path tests/first_expedition.gd).Path
godot --headless --path game --script res://tests/session_test.gd
```

각 실행은 임시 저장·설정 경로를 사용한다. 실측에는 게임 폴더를 복사해 편집기 MCP의 임시 autoload만 제외했다. `--fixed-fps 60`은 실제 시간이 아닌 고정 프레임으로 시뮬레이션을 진행한다. 헤드리스 런타임에서 화면의 그래픽 품질과 GPU 프레임 시간은 측정할 수 없다.

별도의 [세션 테스트](../game/tests/session_test.gd)는 고정 난수 조건에서 **1,176개 검사 통과**를 기록했다. 24개 노선의 보스 주기와 최종 엔딩·재입장, 1~70레벨 가중치, 합성·가방·창고·상점·의뢰, 지연된 중복 처치, 저장 실패 롤백과 손상된 세대 복구를 포함한다. 이 테스트는 세션에 처치 사건을 직접 전달하므로 24개 노선의 실제 입력 완주 시간은 별도로 확인해야 한다.
