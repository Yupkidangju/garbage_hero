# 1080p 필드 전투 성능 기록

구현 변경은 바닥 예고의 메시 생성에 집중한다. 길고 좁은 예고 도형은 길이와 폭 방향을 각각 나누고, 높이가 일정하다고 증명되는 영역은 평면으로 그린다. 지형 높이, 예고의 외곽선, 피해 판정과 시간, 1080p 렌더 설정은 회귀 검사와 같은 조건으로 비교한다.

2026-11-18 · 기준은 [제작 계획](plan.md)의 1920×1080, 불지옥 일반 적 24체와 필드보스 1체, 예열 30초 후 120초의 프레임 간격 95백분위 16.7ms다. 실제 게임 실행 경로에 지정한 전투 배치를 재현하는 [측정 코드](../tests/field_performance.gd)를 사용한다.

첫 통합 측정에서 보고된 중앙값은 18.361ms, 95백분위는 99.771ms였다. 당시 다른 Godot 실행들이 겹쳤다. 동일 장면에서 CPU와 GPU 렌더 시간, 물리 시간, 그림자와 지형 비용을 짧게 비교한 뒤, 효과가 확인된 변경을 반영한 최종 측정과 종료 경고 검사를 기록한다.

## 비용 분해

Windows, AMD Ryzen 7 8845HS, 내장 Radeon 780M, Godot 4.7.2 Forward+ Vulkan에서 측정했다. 화면 배율은 100%이고 3D MSAA는 2×다. 창 위치는 최초 측정과 같은 화면 밖 좌표 `-2400,0`이다. 게임플레이 중 적들의 공격과 이동은 계속되며, 시험 코드가 캐릭터의 체력을 보충한다.

| 조건 | 수집 시간 | 프레임 중앙값 / p95 | Godot 물리 시간 모니터 중앙값 / p95 |
| --- | --- | --- | --- |
| 1920×1080 렌더링, 원래 공격 예고 | 예열 3초 + 9초, 469프레임 | 16.833 / 33.079ms | 33.427 / 64.883ms |
| 같은 배치, 헤드리스 | 예열 3초 + 9초, 1,299프레임 | 6.902 / 13.648ms | 19.238 / 26.134ms |
| 헤드리스, 예고의 지형 높이 투영·세분화 비활성 | 예열 3초 + 9초, 1,305프레임 | 6.902 / 12.734ms | 6.948 / 8.237ms |
| 헤드리스, 적의 물리 갱신 일시 정지 | 예열 3초 + 9초, 1,306프레임 | 6.900 / 7.616ms | 1.333 / 1.767ms |

짧은 렌더링 측정에서 뷰포트 GPU 시간은 중앙값 8.392ms, p95 9.866ms였다. 렌더 CPU 시간은 1.037 / 1.523ms였다. 중앙값 기준 드로 콜은 408회, 프리미티브는 236,777개였다. 헤드리스 진단에는 `--max-fps 144`를 사용했다. Godot 물리 시간은 주기적으로 갱신되는 엔진 모니터 값이어서 개별 프레임의 렌더 시간과 합산할 수 없다. [원본 로그와 진단 스크립트](performance_logs.zip)

헤드리스 대조에서 바닥 예고 메시를 경사에 맞게 세분화하고 높이를 조회하는 비용이 확인됐다. 해당 처리를 끈 경우 물리 모니터 p95가 17.897ms 줄었다. 비교 조건은 진단 목적으로만 사용했다. 지형 접촉과 판정, 화면 해상도, 그림자를 보존하는 후속 후보는 같은 공격 도형의 삼각형 연결 정보를 재사용하고, 실제 경사나 다리와 겹치는 영역만 다시 투영하는 것이다.

## 수정 후 전체 측정

2026-11-18 KST, Ryzen 7 8845HS와 Radeon 780M에서 Forward+, 1920×1080, 2× MSAA, 수직동기화 해제, 창을 화면 밖에 놓은 동일 시나리오를 실행했다. 평면 도형은 큰 면 그대로, 굴곡과 겹치는 도형은 길이·폭에 맞는 격자로 나눴다. 숲 능선에서 높이가 0.660m 바뀌는 구간의 예고 정점 최대 오차는 0.004m였고 교량 검사와 45종·61개 행동 회귀 검사가 통과했다.

예열 30초 뒤 120초 동안 25체를 유지했고 **9,401프레임, 중앙값 13.410ms, p95 20.938ms**를 기록했다. 초기 측정과는 동시 부하 조건에 차이가 있으므로 두 수치의 차이를 전부 코드 변경 효과로 볼 수는 없다. **p95 목표 16.7ms는 미달**이다.

종료 시 남은 참조는 재생 중이던 WAV 두 개와 재생 객체였다. 게임 종료 버튼과 창 닫기에서 재생을 중지하고 오디오 믹서가 참조를 반환할 시간을 둔 뒤 닫도록 수정했다. 두 종료 경로의 헤드리스 검사와 동일 25체 배치의 추가 5초 렌더 검사에서 WAV 참조 잔류·종료 오류는 0건이었다. 이 짧은 렌더 실행에는 Vulkan 레이어 매니페스트 조회와 RGB8→RGBA8 자동 변환에 관한 엔진 경고가 있었다. [종료 재현 테스트](../tests/audio_shutdown.gd)
