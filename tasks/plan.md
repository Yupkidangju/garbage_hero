## 첫 번째 플레이 목표

새 게임에서 **마을 → 쉬움 숲의 두 갈래 길 → 첫 고철검 합성 → 덫뿔사슴 두 번 → 수레등 고목왕 → 마을 마차 → 쉬움 사막 도착**을 일반 입력만으로 완주한다. 숲에서는 도토리쥐와 솔가시벌부터 만들고, 사막은 마차에서 실제로 내려 걸어 다닐 수 있는 도착지까지 연결한다. 이 범위에서 기본 3연격·회피·기술 해금, 가방·창고·저장·재출현을 함께 체험한다.

첫 출발부터 첫 합성까지 1–3분, 첫 필드보스 조우까지 4–7분, 사막 도착까지 7–12분을 **플레이테스트 목표**로 둔다. 새 저장으로 세 번 플레이해 각 시점을 기록하고, 길 찾기나 일반 사냥이 시간을 차지하면 지형 동선·스폰 밀도부터 조정한다.

## Godot 프로젝트 구조와 도구 사용

**Assumption**으로 게임 루트는 `game/`, Blender 원본은 그 밖의 `art/blender/`에 둔다. 게임 렌더러는 PC용 Forward+, 스크립트는 GDScript를 기준으로 한다. 씬 안에는 지형·배치·표현을 두고 몬스터 수치·기술 구간·드롭표는 Godot Resource로 둔다. 같은 필드 씬에 난이도 데이터를 적용해 24개 노선의 지형 수정이 여섯 곳에서 끝나게 한다.

| 계획 경로 | 책임과 연결 |
| --- | --- |
| `game/project.godot`, `game/scenes/main.tscn` | 시작 씬을 연결한다. 저장을 읽어 마을에 배치하고 마차·귀환 요청에 따라 필드와 HUD를 바꾼다. |
| `game/scenes/town/`, `game/scenes/fields/` | 마을 서비스 지점, 필드의 연결된 길·귀환 표석·몬스터 및 보스 출현 공터를 소유한다. |
| `game/data/` | 테마 기본 레벨, 일반 적 목록, 보스 쌍, 지역 도안, 난이도, 행동별 준비·판정·회복과 등급 가중치의 원본이다. |
| `game/scripts/combat/`, `game/scripts/hunt/` | 물리 틱에서 이동과 타격을 해결한다. 한 개체가 쓰러지면 개체 번호와 노선을 사냥·드롭 처리에 넘긴다. |
| `game/scripts/loot/`, `game/scripts/save/` | 드롭 판정·도안·등급·능력치를 순서대로 뽑는다. 습득·합성·거래·보스 해금을 저장 순번 단위로 확정한다. |
| `game/scenes/ui/` | 저장된 장비와 사냥 진행을 표시하고, 합성·거래·노선 선택 요청을 보낸다. 성공·실패 결과에 맞춰 화면을 갱신한다. |
| `art/blender/`, `game/assets/` | 편집용 모델·리그·액션과 게임용 GLB·셰이더·메시 효과를 나눈다. Godot에서 합성한 캐릭터 씬에 소켓·효과를 붙여 GLB 재임포트를 견디게 한다. |

한 개체의 **처치 확정 → 사냥 상태 갱신과 드롭 생성 → 저장 → HUD와 필드에 반영**을 함께 처리한다. 가방 거래는 **새 재료 확인 → 보호 여부 확인 → 연속 합성 계산 → 최종 수량·난수 상태 저장 → 비교 표시** 순서를 따른다. 구매라면 코인과 재고도 같은 거래에 포함한다. 마차는 저장된 최초 클리어 기록으로 목적지를 계산한다.

첫 구현에서 `game/project.godot`와 시작 씬을 연결한 뒤 Godot MCP의 `get_project_info`에 해당 폴더를 전달한다. `create_scene`와 `batch_scene_operations`로 씬을 구성하고 `get_scene_tree`·`validate`로 노드와 스크립트를 확인한다. 아래 명령은 **향후 프로젝트 루트에서** 실행하는 임포트·기동 확인이다.

```powershell
godot --headless --path .\game --import
godot --headless --path .\game --quit-after 120
```

화면·입력 검증은 MCP `run_project`로 창이 있는 게임을 띄워 브리지 준비를 확인한 뒤 `simulate_input`, `get_ui_elements`, `take_screenshot`, `get_debug_output`을 사용하고 `stop_project`로 종료한다. 마차 목적지와 합성 결과는 일반 게임 입력으로 도달해 확인한다. 보스 상태 건너뛰기나 장비 강제 지급은 수치 경계 테스트에만 사용한다.
