# 고물용사 구현 체크리스트

2026-11-18 KST. 체크된 항목은 해당 작업의 기능과 명시된 검사를 수행한 범위다. 미체크 항목에도 이미 실행 가능한 기능이 있으며, 추가로 필요한 검사는 구현 기록에 적었다. [게임 기획서](../spec.md) · [전투·아트 설계](../designs.md) · [제작 계획과 실행 명령](plan.md) · [구현 기록](../IMPLEMENTATION_SUMMARY.md)

## A · 이동과 전투 시험장

- [x] **A1 · 첫 실행.** 게임 루트와 시작 씬을 연결한다. Godot MCP가 프로젝트를 읽고, 헤드리스 임포트와 창에서의 시작·종료가 성공하는지 확인한다.
- [x] **A2 · 숲을 걷기.** A1 이후 사선 카메라, 지면 이동, 장애물 가림 처리를 만든다. 두 갈래 길을 반대 방향으로 각각 왕복하고 벽·귀환 표석의 충돌을 확인한다.
- [x] **A3 · 숲의 첫 전투.** A2 이후 도토리쥐와 솔가시벌, 기본 3연격·회피·갈퀴를 연결한다. 30/60/120 렌더 FPS에서 각 타격 수, 회피 거리, 벽 충돌을 비교한다.
- [x] **A4 · 주인공 아트 기준.** A2 이후 Blender의 주인공·고철검·리그와 대표 베기 클립을 GLB로 이관한다. A3의 전투에 적용하고 8방향 실루엣·손잡이·양발 접지를 확인한다.

## B · 숲에서 사막까지

- [x] **B1 · 첫 전리품.** A3 이후 숲의 두 무기 도안과 개체별 드롭을 연결한다. 새 슬롯 데이터에서 3·6·9번째 일반 처치 보상이 각각 한 번씩 나오고, 줍기 전후 같은 무기 번호가 유지되는지 확인한다.
- [x] **B2 · 첫 합성.** B1 이후 가방의 자동/수동 합성·보호·결과 비교·회오리 해금을 만든다. 같은 도안 2/3/9개, 혼합 등급, 잠금, 신화급, 만원인 가방을 검사한다.
- [x] **B3 · 원정 재개.** B2 이후 저장 교체와 창고 입출고를 연결한다. 합성이나 이동 직전·직후에 재시작하고 무기 번호·수치·슬롯 수가 일치하는지 확인한다.
- [x] **B4 · 덫뿔사슴.** A3·B3 이후 흔적 12에서 예고하고 첫 중간보스를 소환한다. 흔적 11에서 귀환하거나 보스를 남겨 두고 재접속해 같은 주기를 이어 간다.
- [x] **B5 · 수레등 고목왕.** B4 이후 두 번째 사슴 처치로 고목왕의 공터와 두 패턴을 연다. 한 주기에 한 마리가 나오고, 승리 후 휴식과 재사냥으로 두 번째 고목왕이 나오는지 확인한다.
- [x] **B6 · 마차 노선.** B3·B5 이후 쉬움 숲 첫 승리로 사막과 압착 강타를 연다. 마을 귀환, 마차 탑승, 사막 하차와 이동, 저장 재개를 일반 입력으로 검증한다.
- [x] **B7 · 첫 원정 완주.** A4·B6 이후 촌장 첫 의뢰와 보상을 연결한다. 새 저장으로 첫 합성·첫 보스·사막 도착 시간을 기록하고, 기술 3종과 재방문을 확인한다.

## C · 한 필드의 완성도

- [ ] **C1 · 숲 전투 구성.** B7 이후 이끼멧돼지·껍질방패충·버섯북장이를 더한다. 일반 5종을 각자 상대하고, 돌진 회피·정면 방어 우회·가속 담당 우선 처치를 실제 플레이로 확인한다.
- [x] **C2 · 마을 경제.** B7 이후 상설 상인·이동상인과 테마별 촌장 의뢰를 연결한다. 방문·매진·재출발·늦은 의뢰 수령·저장 재개에서 재고와 보상 횟수를 확인한다.
- [x] **C3 · 숲의 화면 품질.** A4·C1 이후 사슴·고목왕 리그, 등급별 고철검 외형, 세 기술의 메시 효과와 예고 음향을 완성한다. 손·발·관통·타격 동기와 흔들림/섬광 약화 상태를 영상으로 검토한다.

## D · 콘텐츠와 난이도 확장

- [x] **D1 · 첫 난이도 변형.** C1·C3 이후 숲에 혼합 무리와 후속 패턴을 적용한다. 네 난이도에서 적 상한과 레벨이 맞고 보스 패턴에 걸어 나갈 틈이 있는지 확인한다.
- [x] **D2 · 사막과 묘지.** C2·D1 이후 사막(일반 6종)과 묘지(5종)를 한 곳씩 제작한다. 각 지역의 중간보스·필드보스 한 주기, 고유 무기 드롭과 다음 마차 노선을 별도로 검증한다.
- [x] **D3 · 늪과 설산.** D2 이후 늪(6종)과 설산(5종)을 한 곳씩 제작한다. 수문·빙판 위에서 길 찾기와 예고가 작동하고, 각 지역의 보스 재출현과 해금이 성립하는지 확인한다.
- [x] **D4 · 화산과 엔딩.** D3 이후 화산(6종)과 보스 한 쌍을 제작한다. 첫 세 난이도의 화산은 다음 숲, 불지옥 화산은 엔딩과 자유 재방문으로 이어지는지 확인한다.

## E · 전체 검증

- [x] **E1 · 경제와 저장.** D4 이후 모든 필드 레벨의 드롭표와 7등급 평균을 계산한다. 합성·거래·처치 저장 실패를 주입해 재시도 중복과 유실을 확인한다.
- [ ] **E2 · 플레이와 표현.** D4 이후 새 저장 한 개의 24노선 진행, 일반 33종·중간 6종·필드보스 6종 실제 조우를 기록한다. 작은 화면·큰 글자·키 재지정으로 주요 메뉴를 다시 조작한다.
- [ ] **E3 · 고밀도 전투.** C3·D4 이후 기준 PC에서 1080p, 일반 적 24체+보스 1체, 메시 효과를 갖춘 120초 전투를 측정한다. 프레임 시간과 실제 패턴 가독성을 함께 기록한다.

숲의 5종은 모두 등장하고 고유 행동을 수행한다. C1의 전술적 가독성은 사람이 방패와 가속 담당을 구별해 대응하는 플레이로 추가 확인한다. 전체 캠페인의 실제 입력 도달 지점과 E3의 수치는 각각 [캠페인 기록](campaign_input_results.md), [성능 기록](performance_results.md)에 있다.
